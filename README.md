# Traveler Type Classification Application

This repository contains an interactive Streamlit application developed to classify rail travelers based on behavioral preferences and current tourism trends.

The application is grounded in the research presented in the paper:

**“A PLS-SEM Model to Analyse Rail Tourists’ Perceptions in Relation to Current Tourism Trends”**

The study examines how Rail Tourism Preference is shaped through the interaction of:

- Digital Technologies
- Post-Pandemic Health & Safety
- Sustainability
- Rural Access
- High-Value Experiences

The application translates the empirical findings and PLS-SEM outputs of the research into an interactive decision-support and recommendation tool. :contentReference[oaicite:0]{index=0}

## Features

- Interactive traveler classification questionnaire
- Behavioral traveler archetype detection
- Hybrid traveler profile generation
- Personalized rail route recommendations
- Comparison with survey averages
- Indicator-by-indicator preference analysis
- Interactive visualizations using Streamlit and Matplotlib

## Methodology

The classification system is based on:

- PLS-SEM construct relationships
- Indicator outer loadings
- Weighted behavioral scoring
- Correlation and profile clustering logic
- Direct and indirect construct relationships

The application uses weighted indicators derived from empirical survey data and structural modelling results. :contentReference[oaicite:1]{index=1}

## Research Context

This application was independently developed as an additional research-oriented extension inspired by the findings of a Master's research project in Transportation Engineering focused on rail tourism, behavioural modelling, and experiential travel analysis.

The goal was to translate PLS-SEM results and behavioural segmentation insights into an interactive user-facing decision-support application.
